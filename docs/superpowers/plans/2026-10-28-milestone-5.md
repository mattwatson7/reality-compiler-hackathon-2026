# Milestone 5 implementation plan

**Goal:** Evaluate real footage honestly and compare independently compiled procedures against immutable evidence in the browser.

**Architecture:** Keep completed jobs as immutable perception records. Store append-only evaluation snapshots in SQLite. A pure compatibility gate maps exact object/region definitions and typed predicates across independently compiled IDs; preserve repeated and unusable observations. Never dispatch perception during re-evaluation. Incompatibility records UNKNOWN and requests a fresh upload/selection. Retain the existing expiry and budget policies.

**Execution:** Inline, with test-first deterministic logic. The user's objective authorizes autonomous implementation and supersedes skill review pauses.

- [x] Inspect all supplied videos, full decode, hashes, representative frames and source/license research; select bounded continuous segments before model outcomes.
- [x] Add regression tests for unchanged evidence with reversed order, changed object/region/predicate, unsupported requirements, repeated/ambiguous observations, persistence, expiry and tampering.
- [x] Implement compatibility module, append-only store, bounded API and independent compilation. Preserve original results and perception, including source/provenance fingerprints.

## Design limits

Exact semantic matching is deliberately conservative: synonyms, changed region geometry, different object descriptions, new predicates and changed scope need new perception unless the stored observation contract explicitly supports them. No filename-specific evaluation. Two-dimensional overlap never proves containment/contact/insertion. Generated/replayed/synthetic inputs remain separately labeled from genuine camera recordings. Original controlled held-out acceptance remains outstanding.
